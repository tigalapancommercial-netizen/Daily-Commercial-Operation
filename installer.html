Pembuat index.html v26

Alat lokal ini membuat HTML aplikasi lengkap dari index.html asli Anda dengan menyisipkan satu skrip perbaikan UI. Semua menu, form, dan skrip asli tetap berada di file hasil.

PentingHalaman ini adalah installer lokal, bukan index.html aplikasi untuk di-deploy. Fitur auto-restore draft v25 harus diuji terpisah, karena hotfix ini hanya mengubah tampilan.
  1. Backup index.html lama.
  2. Upload file index.html yang baru dibuat ke root repository.
  3. Upload public/dco-v26-ui-hotfix.js dari paket ini ke folder public/.
  4. Commit, build/deploy, lalu uji seluruh menu, draft, foto, HP, dan desktop.
Proses dilakukan di browser Anda. File diproses lokal dan tidak dikirim ke server lain. Jangan hapus storage browser jika masih ada draft belum tersinkron.
